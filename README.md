# Чат бот модератор для Telegram.

### Команды:

+ник {ник} / -ник - Установить/сбросить кастомный ник (отображается в топе и РП)

+описание {описание} / -описание - Установить/сбросить описание (отображается в кто я/кто ты)

поженить пару @user1 @user2 - Принудительно зарегистрировать брак между участниками (только администраторы группы)

кто я/кто ты - показывает статистику о пользователе

После выхода или бана участник скрывается из статистики на неделю. Если он вернётся в течение 7 дней, статистика восстановится; после этого срока данные будут удалены.

какая нагрузка - выполняет команду uptime и отправляет её вывод

топ неделя/день/месяц/вся - Показывает недельную/дневную/месячную/всю статистику участников чата

пинг/кинг/бот - Команды для проверки работоспособности бота

бан [срок] - Блокировка пользователя (например: бан неделя, бан 3 месяца, бан год; без срока — бессрочно)

разбан - Разблокировка пользователя

мут [срок] - Лишение права слова пользователя (например: мут 20 минут, мут 3 дня; без срока — бессрочно)

размут - Выдача права слова пользователю

кик - Изгнание пользователя из группы (Не путать с блокировкой! При блокировке пользователь не может вернуться в группу.)

рандом a b - Выбирает случайное число из диапазона чисел a..b

моя статья - Случайная статья УК РФ для автора команды (шутка)

Каталог [criminal_code_articles.json](./criminal_code_articles.json) содержит 535 номеров и названий статей и предусмотренные законом санкции по частям (где они есть) в редакции УК РФ от 09.04.2026; [источник](https://www.consultant.ru/document/cons_doc_LAW_10699/). Это не статистика фактических приговоров.

пин/закреп - Закрепление сообщения

анпин - Открепление сообщения

-чат - отключение чата (мут всех, кроме администрации)

+чат - включает чат

-смс - удаляет сообщение

.хелп - выводит справку по командам

Варн [срок] / Снять варн - Выдача/Снятие предупреждения пользователю (например: варн 3 дня, варн 1 месяц)

Варны - Просмотр активных предупреждений в группе

Лимит варнов [число] - Настройка количества варнов до бана для группы (только админы и создатель)

Время варна [срок] - Настройка времени действия варна по умолчанию для группы (например: время варна 1 месяц; только админы и создатель)

Для сроков поддерживаются секунды, минуты, часы, дни, недели, месяцы (30 дней) и годы (365 дней); можно указывать составные сроки, например «2 недели и 3 дня».

+админ - Выдача прав администратора пользователю

-админ - Снятие прав администратора пользователю

Барбарис, скажи - Повторяет за вами

Барбарис да нет {вопрос} - Отвечает случайной вероятностью от 0 до 100%

Барбарис кто {вопрос} - Случайно выбирает участника чата и отвечает на вопрос

Шипперим - Выбирает двух случайных участников чата и шипперит их (совместимость в %, пейринг и забавный комментарий)
